Data Quality & Preprocessing

This part of the project is the foundation. It transforms noisy hospital records and unstructured surgeon notes into a reliable feature set for prediction.

Records

14,834 surgical records processed with structured and unstructured fields.

Missing Data Rules

Columns with more than 40% missing values were dropped, and targeted imputation preserved clinical context.

Text Preprocessing

Byte-Pair Encoding was applied to surgeon descriptions to convert text into numeric vectors.

The preprocessing pipeline has three main stages:

  • Data quality validation and duplicate removal.
  • Missing-value treatment by feature type and clinically informed imputation.
  • Feature transformation, including categorical encoding, cyclic time encoding, and text vectorization.

Critical preprocessing code

import pandas as pd
import numpy as np
from sklearn.preprocessing import OneHotEncoder
from sentencepiece import SentencePieceProcessor

# Load data
raw_df = pd.read_csv('surgery_data.csv')

# Remove exact duplicates and invalid rows
raw_df = raw_df.drop_duplicates()
raw_df = raw_df[raw_df['duration_minutes'].notna()]

# Drop low-quality columns
missing_ratio = raw_df.isna().mean()
keep_columns = missing_ratio[missing_ratio <= 0.40].index.tolist()
df = raw_df[keep_columns].copy()

# Impute critical clinical features
impute_map = {
    'anaesthesia_type': 'unknown',
    'team_surgeon': 'missing',
    'procedure_description': 'not available',
}
for col, filler in impute_map.items():
    if col in df.columns:
        df[col] = df[col].fillna(filler)

# Standardize text fields
text_cols = ['procedure_description', 'surgeon_notes']
for col in text_cols:
    df[col] = (
        df[col].astype(str)
             .str.lower()
             .str.replace(r"[^a-z0-9 ]", ' ', regex=True)
             .str.replace(r"\s+", ' ', regex=True)
             .str.strip()
    )

Feature preparation

We separate the full preprocess into a stable dataset and a precision dataset. The stable dataset preserves all rows with single-value imputation, while the precision dataset drops rows with remaining data issues.

def encode_cyclic(df, col, max_value):
    df[f'{col}_sin'] = np.sin(2 * np.pi * df[col] / max_value)
    df[f'{col}_cos'] = np.cos(2 * np.pi * df[col] / max_value)
    return df

if 'scheduled_month' in df.columns:
    df = encode_cyclic(df, 'scheduled_month', 12)
if 'scheduled_weekday' in df.columns:
    df = encode_cyclic(df, 'scheduled_weekday', 7)

# Build the stable dataset and high-precision dataset
stable_df = df.fillna({'charge_code': 'unknown', 'priority': 'standard'})
precision_df = df.dropna()

Text vectorization with BPE

Byte-Pair Encoding converts surgeon descriptions and procedure notes into compact numeric representations that preserve medical phrase structure.

sp = SentencePieceProcessor(model_file='bpe_model.model')

def bpe_encode_text(series):
    return np.array([sp.encode_as_ids(text) for text in series], dtype=object)

procedure_tokens = bpe_encode_text(stable_df['procedure_description'])
stable_df['proc_bpe_ids'] = procedure_tokens

For modeling, the token sequences were aggregated into count-based or embedding-based features, such as token density, rare-term presence, and average token index.

Model Design & Stacking

The model architecture combines single-model development with a proper stacking ensemble. The pipeline begins with a tuned LightGBM baseline, then blends multiple learners through out-of-fold predictions and an ElasticNet meta-learner.

Single model development

After Completed a systematical selection of 20 different models, LightGBM is selected as the main baseline model. Training uses a log-transformed target and duration-weighted sample weights to handle skewed surgery duration values while preserving minute-level prediction accuracy.

Hyperparameter tuning

Optuna optimizes model quality while punishing excessive generalization gaps and poor test performance. The custom objective combines MAE, RMSE, R², and model stability into a single penalty score.

def penalty_objective(y_train, y_test, y_tr_pred, y_te_pred):
    mae_te = mean_absolute_error(y_test, y_te_pred)
    r2_tr = r2_score(y_train, y_tr_pred)
    r2_te = r2_score(y_test, y_te_pred)
    gap = abs(r2_tr - r2_te)

    penalty = 0.0
    if mae_te > 28.0:
        penalty += (mae_te - 28.0) * 1000
    elif mae_te > 29.0:
        penalty += (mae_te - 29.0) * 50

    if gap > 0.05:
        penalty += (gap - 0.05) * 10000

    if r2_te < 0.80:
        penalty += (0.80 - r2_te) * 1000

    return mae_te + penalty
