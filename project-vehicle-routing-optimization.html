Vehicle Routing & Zone Optimization

This project solves a complex logistics challenge by automatically designing delivery zones and optimizing daily vehicle routes to minimize total travel distance across a network of 30 customer sites.

Combinatorial Optimization K-Means Clustering TSP Solving Parallel Processing

Problem Statement

A delivery company operates a network of 30 customer sites with periodic demand patterns (Monday–Friday). The goal is to partition these sites into exactly 3 delivery zones, where each zone is served by one delivery person. The zones must be fixed once designed, and the challenge is to find the optimal zoning that minimizes the total weekly delivery cost (sum of travel distances) across all days.

Key Constraints

  • Exactly 3 zones, each served by one delivery person.
  • Each zone cannot exceed 12 customer sites.
  • Customer demand varies by day (some sites don't need service every day).
  • Zones can overlap: a customer can belong to multiple zones and be served by different staff on different days.
  • Distance measured using Manhattan distance metric.

Approach & Techniques

The solution uses a multi-stage optimization pipeline:

  • Clustering: K-Means clustering to create initial zone assignments based on geographic proximity.
  • Capacity Handling: Post-processing to ensure no zone exceeds 12 sites; customers are moved between zones based on distance to centroids.
  • Strategic Overlaps: Selected customers from adjacent clusters are added to neighboring zones to improve flexibility for daily assignments.
  • Daily Assignment: For each day, shared customers (those in multiple zones) are greedily assigned to their closest zone centroid.
  • TSP Solving: Google OR-Tools to find near-optimal travel routes for each zone on each day.
  • Parallel Optimization: Multiple zoning configurations evaluated in parallel using multiprocessing to find the global best.

2. TSP Solver using OR-Tools:

def solve_tsp(nodes):
    manager = pywrapcp.RoutingIndexManager(len(nodes), 1, 0)
    routing = pywrapcp.RoutingModel(manager)
    
    def distance_callback(from_index, to_index):
        from_node = manager.IndexToNode(from_index)
        to_node = manager.IndexToNode(to_index)
        return distance_matrix[nodes[from_node]][nodes[to_node]]
    
    transit_callback_index = routing.RegisterTransitCallback(distance_callback)
    routing.SetArcCostEvaluatorOfAllVehicles(transit_callback_index)
    
    search_parameters = pywrapcp.DefaultRoutingSearchParameters()
    search_parameters.first_solution_strategy = routing_enums_pb2.FirstSolutionStrategy.PATH_CHEAPEST_ARC
    search_parameters.local_search_metaheuristic = routing_enums_pb2.LocalSearchMetaheuristic.GREEDY_DESCENT
    search_parameters.time_limit.seconds = 1
    
    solution = routing.SolveWithParameters(search_parameters)

def cluster_zoning(num_zones=3, max_zone_size=12, overlap=3):

    zones = {i+1: [] for i in range(num_zones)}
