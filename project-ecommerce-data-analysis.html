E-Commerce Data Analysis

This project captures the end-to-end process of web scraping product data, cleaning and normalizing datasets, and using visual analytics to identify the factors that influence Amazon product sales.

Web Scraping Data Cleaning Visualization Machine Learning Prep

Project Summary

This project investigates how product attributes such as price per count, star rating, and comment volume affect sales across three product categories: coffee pods, sanitary pads, and induction cooktops. It uses Python-based scraping and data analysis to build practical insights for e-commerce decision-making.

Data Collection & Tools

  • Collected Amazon product data using Python libraries: requests, BeautifulSoup, and cloudscraper.
  • Crawled multiple pages for each product category and extracted title, price, star rating, comment count, and sales metrics.
  • Saved the cleaned datasets into CSV files: coffee_pod_data.csv, sanitary_pad_data.csv, induction_cooktop_data.csv, and cross_data.csv.
  • Prepared data for analysis using pandas, numpy, seaborn, and matplotlib.

Data Processing

The raw scraped data was cleaned by removing outliers, normalizing numerical attributes, and inverting the star rating scale to make higher satisfaction values easier to compare visually. The analysis used statistical filtering and data normalization to prepare the results for robust visualization.

Q1 = df['Price per count'].quantile(0.25)
Q3 = df['Price per count'].quantile(0.75)
IQR = Q3 - Q1
clean_df = df[(df['Price per count'] >= Q1 - 1.5*IQR) & (df['Price per count'] <= Q3 + 1.5*IQR)]

Visual Analysis & Results

Star Rating Trends

Density plots showed most products concentrate around higher star values, suggesting customer satisfaction is strong across categories.

Price Distributions

Induction cooktops had the highest price density peak, while sanitary pads showed the broadest pricing range and coffee pods fell in between.

Sales Correlations

Regression analysis revealed a weak negative price-sales relationship for sanitary pads and cooktops, and a slight positive sales trend for coffee pods.

Comment Engagement

Comment count densities indicated low engagement for all categories, but higher comment activity tended to correlate with stronger sales.

Practical Skills Demonstrated

  • Web scraping and handling anti-bot defenses with user-agent rotation and cookies.
  • Data cleaning, outlier filtering, and feature engineering in Python.
  • Exploratory data analysis using visual tools like KDE plots, scatter plots, and regression lines.
  • Working with multiple datasets and merging results for cross-category comparisons.

Conclusion

This project shows how data-driven e-commerce analysis can reveal insights beyond price alone. By combining scraping, normalization, and visual analysis, it highlights the importance of star ratings, comment engagement, and pricing structure in predicting product sales performance.
