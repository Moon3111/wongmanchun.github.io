IEDA 3302: E-Commerce Technology and Applications
The project must investigate a particular question that is related to E-Commerce, and must require the
collection, organization, visualization and analysis of data collected from the web. Typical aspects involved
in each project must illustrate tool used in E-Commerce, including:
(a) Collecting and organization of information.
The project may use web crawling and parsing for information on your topic of choice. For some
particular topics, data-sets from gapminder.org can be used (see below).
(b) You can use any convenient crawling+parsing library to facilitate your data collection (e.g.
BeautifulSoup).
(c) You must use selected and appropriate visualization tools to investigate the problem data, and as an
aid to modeling/analysis, as well as to present the findings.
(d) The data analysis and conclusions must use some subset of the analytics techniques that are covered
in the course.
