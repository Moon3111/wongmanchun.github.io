Inference for Learning Agents

Inferring private bidder values from quality-weighted first-price auction bids and evaluating downstream revenue optimization.

Auction Theory No-Regret Learning Causal Inference Simulation Mechanism Design

Project Overview

This project studies quality-weighted first-price auctions in display advertising, where advertisers learn bids through a no-regret algorithm. It uses observed bid sequences to infer private bidder values and then evaluates whether those estimates can improve auction revenue through reserve pricing.

Objective

  • Recover private bidder values from noisy learning-based bids in a quality-weighted first-price auction.
  • Measure how the rationalizable value set changes as auction rounds increase.
  • Compare a midpoint estimator against the true values and study inference accuracy.
  • Evaluate whether inferred values can inform a revenue-enhancing reserve price.

Approach

The study simulates five bidders over auction rounds, with each bidder using a multiplicative weights update algorithm to minimize regret. Match qualities are drawn independently from U[0,1] each round, and the auction winner is determined by the highest quality-weighted bid.

Inference Method

Construct the rationalizable set of values consistent with observed bids under ε-regret. Point predictions are derived from the midpoint of this interval, and the resulting estimates are used to compute reserve prices.

Key Metrics

Bidder Count

5 advertisers using quality-weighted first-price bidding.

Rounds Tested

50, 100, 250, and 500 auction rounds per trial.

Learning Rule

Multiplicative Weights Update with η = 0.08.

Reserve Impact

Revenue gain was negative at all horizons, improving from −30.5% to −8.8% as T increased.

Findings

As auction rounds increase, the rationalizable set narrows and inference accuracy improves. The midpoint estimator's MSE fell by nearly 79% from T = 50 to T = 500, while coverage rose to 99% at the longest horizon.

  • Rationalizable set width decreased from approximately 0.70 at T = 50 to 0.49 at T = 500.
  • MSE dropped from 0.075 to 0.016, indicating more accurate inferred values with more data.
  • Coverage reached 99% at T = 500, supporting the theoretical containment guarantee.
  • Reserve pricing based on inferred values remained revenue-negative due to upward bias in the midpoint estimator.

Implications

The project illustrates that bid-based inference can recover useful information about bidder values, but it also highlights the risks of applying those estimates directly to reserve pricing without accounting for estimator bias and uncertainty.

  • Inference is feasible, but convergence can be slow when match qualities add noise.
  • The midpoint of the rationalizable set is convenient but biased, especially for low-value bidders.
  • Revenue optimization requires caution; a noisy inferred reserve can reduce auction performance.
  • Future work should explore alternative point estimators and adaptive reserve rules based on estimation uncertainty.
