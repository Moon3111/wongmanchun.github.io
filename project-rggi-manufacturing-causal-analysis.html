RGGI Manufacturing Causal Analysis

IEDA 4000D — Geographic RDD and DiD evaluation of carbon tax impacts

Project Overview

This project explores whether the 2009 implementation of the Regional Greenhouse Gas Initiative (RGGI) caused manufacturing employment or establishment relocation from RGGI border counties to neighboring non-RGGI border counties.

Core Question

Did the RGGI carbon tax induce a measurable ‘‘carbon leakage’’ effect in manufacturing employment and establishments?

Methodology

Data Preparation

Used 2000–2024 annual county-level BLS QCEW data for manufacturing employment and establishments. Constructed a border county panel for 73 counties across 8 states with 76 matched pairs.

Empirical Strategy

Combined Geographic Regression Discontinuity Design (RDD) with a Two-Way Fixed Effects Difference-in-Differences (DiD) framework. The border-county design controls for shared geography, local economic conditions, and labor markets.

Y_it = β₀ + β₁(Is_RGGI_i × post_2009_t) + α_i + γ_t + ε_it Where: - Y_it = log employment or log establishments - Is_RGGI_i = 1 for RGGI border counties - post_2009_t = 1 for years ≥ 2009 - α_i = county fixed effects - γ_t = year fixed effects

Results

Key Findings

Visual Summary

This analysis confirms a null effect for RGGI on manufacturing employment and establishments across matched border counties. The result is supported by parallel-trends validation and placebo test checks.

Statistically significant impact

The analysis finds no statistically significant evidence that RGGI caused manufacturing employment or establishments to decline in RGGI border counties relative to matched non-RGGI border counties.

Robustness

Validation Steps

  • Parallel trends validated using 2000–2008 pre-treatment data
  • Placebo tests for 2005 and 2007 showed no significant effects
  • Robust standard errors (HC3) used due to limited state clusters

Conclusion

The null result is consistent across specifications, suggesting that RGGI did not cause manufacturing job or factory migration at the border-county level.

Implications

  • Policy Insight: Emissions pricing may not necessarily induce manufacturing relocation when neighboring areas are economically similar.
  • Future Research: Apply staggered DiD methods to account for New Jersey’s temporary RGGI exit and further test heterogeneous effects.
  • Data Work: Use county-pair panel data with fixed effects to minimize local confounders and strengthen causal claims.
