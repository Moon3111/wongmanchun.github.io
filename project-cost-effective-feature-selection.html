Cost-Aware Feature Selection

This project explores how to select predictive features with cost sensitivity, using a modified L1-SVM formulation cast as a mixed-integer linear program (MILP). The goal is to produce accurate models while keeping feature acquisition cost manageable.

SVM MILP Feature Selection Cost Sensitivity

Project Overview

In this work, I developed a feature selection strategy that extends L1-norm Support Vector Machine to account for the cost of each feature. This approach seeks to identify feature subsets that maintain classification performance while reducing real-world acquisition and computation costs.

Challenge

Traditional feature selection methods focus mainly on predictive accuracy, often ignoring the cost associated with collecting and using features in real-world applications. This can lead to impractical systems when expensive or resource-intensive features are included.

Approach

  • Modelled L1-SVM as a mixed-integer linear program (MILP) to introduce a structured and solvable optimization formulation.
  • Extended the model to incorporate feature costs, encouraging low-cost feature sets that still perform well.
  • Analyzed how cost uncertainty affects model robustness and proposed adjustments to handle varying feature expenses.
  • Tested the model using provided datasets and compared its performance against standard feature selection approaches.

Key Deliverables

  • Developed a cost-effective feature selection framework using SVM and MILP.
  • Built a robust formulation to mitigate uncertainty in feature costs.
  • Applied the method to real data and compared it with alternative models.
  • Documented the assumptions, results, and practical implications of cost-aware feature selection.

Impact

This project demonstrates how optimization techniques can be combined with machine learning to create solutions that are better aligned with real-world constraints. It highlights the importance of balancing model effectiveness with feature acquisition costs, especially in applications where resources are limited.
