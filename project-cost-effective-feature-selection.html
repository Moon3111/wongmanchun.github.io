Cost-Aware Feature Selection

This project develops a cost-sensitive feature selection framework by extending L1-norm SVM into a MILP formulation. The goal is to balance diagnostic accuracy with feature acquisition cost in healthcare decision support.

Target

Minimize feature cost while preserving classification accuracy.

Approach

Mixed-integer programming with budget constraints and robustness to cost uncertainty.

Outcome

20% accuracy gain with improved model reliability on clinical data.

Python MILP SVM Feature Selection Healthcare

Introduction

The project addresses the challenge of high-dimensional data and the curse of dimensionality by incorporating feature acquisition cost into the selection process. It focuses on healthcare applications, where medical testing costs and resource limits make cost-aware feature selection critically important.

Objective

Build and compare cost-effective and robust feature selection models that maintain high accuracy while minimizing the total cost of selected features. The analysis also explores group-based feature selection and demonstrates a computational strategy for solving complex MILP models.

Approach

  • Extended ℓ1-SVM into a mixed-integer linear program (CESVM1) with a budget constraint to select informative, low-cost features.
  • Introduced binary selection variables to enforce a budget limit on total feature cost and activated model weights only for selected features.
  • Built a robust variant (RCESVM1) that accounts for feature cost uncertainty using a conservatism parameter, Γ, to improve real-world reliability.
  • Explored group feature selection with GFS-CESVM1 and GFS-RCESVM1, handling grouped features under budget restrictions.
  • Applied a Branch-Cut-and-Price (BCP) algorithm to manage MILP complexity and improve solution performance.

Data and Context

Study data focuses on Chronic Kidney Disease (CKD), where early detection is essential. CKD is a progressive condition with serious health consequences, and the project examines how cost-aware feature selection can reduce unnecessary tests while preserving model accuracy.

Results

Accuracy Improvement

Achieved a 20% increase in accuracy after applying robust, cost-aware selection techniques.

Recall

Recorded a recall rate of 1.0, demonstrating the model detected all CKD cases in the test data.

F1 Score

F1 performance improved significantly, showing a strong balance between precision and recall.

The results indicate that robust cost-aware feature selection can reduce false positives and improve the practical reliability of CKD screening models.

Key Insights

  • Cost-aware selection helps avoid impractical models that use expensive features with marginal accuracy gains.
  • Robust optimization under cost uncertainty increases model stability and makes predictions more trustworthy.
  • Feature group selection provides a structured way to manage correlated or related clinical features within a budget.
  • Using financial and computational constraints together leads to more usable healthcare decision support tools.

Conclusion

The project demonstrates a practical framework for cost-effective and robust feature selection in machine learning. By integrating budget constraints and uncertainty handling into SVM-based feature selection, the approach supports better decision-making in applications where resource use and expense matter.
